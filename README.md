### Como ejecutar la tarea:

1. Clonar el repositorio:

```bash
git clone https://github.com/Diplomatura-Full-Stack-Developer/Angular-M1-T4

```

1. Instalar las dependencias:

```bash
npm install
```

1. Ejecutar la aplicación:

```bash
ng serve
```
